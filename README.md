# RIMBA Enumerator Tracker

Aplikasi web/PWA untuk membantu enumerator mengelola responden, nomor kuesioner, dokumentasi foto, dan progres survei Koridor RIMBA.

## GitHub Pages

Upload seluruh isi repository ke branch `main`, lalu aktifkan GitHub Pages dari **Settings → Pages → Source: GitHub Actions**.

Aplikasi sudah dilengkapi web app manifest dan ikon 192x192 serta 512x512 agar dapat dipasang sebagai aplikasi di perangkat yang mendukung PWA.
